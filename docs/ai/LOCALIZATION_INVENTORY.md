# Azerbaijani localization inventory

Last inventoried: 2026-07-26. Default document language: `az`. Formatting locale: `az-AZ`.

This is the durable user-visible string inventory for P1-010. “Complete” means the named surface is centralized and verified for the current repository state; it does not make L10N-01 complete while pending rows remain.

## Contract

- `lib/i18n.ts` is the single current Azerbaijani copy, marketplace-label, money, and date contract. Add new launch copy there instead of scattering literals.
- English category, condition, city, sort, and status values remain stable database/API/query codes. The UI translates their presentation only. Unknown or user-entered values pass through unchanged.
- User-entered book titles, authors, descriptions, reviews, and messages are never translated.
- Azerbaijani text must use `ə, ğ, ç, ş, ı, İ, ö, ü` correctly. Root fonts load Latin Extended glyphs.
- Legal operator name, address, contact, retention promises, regulator details, and production-domain facts must remain blocked until supplied and reviewed; no placeholder may impersonate a legal fact.
- Internal error codes, log messages, source identifiers, CSS text, test fixtures, and administrator-only database diagnostics are not UI copy unless a component or response exposes them to a user.

- Browser review at 1440x900, 1024x768, 390x844, and 360x800 checks `lang=az`, Latin Extended glyphs, wrapping/reflow, keyboard names, loading/empty/error variants, title/description metadata, and zero unexpected console/network failures.
- A UTF-8/mojibake scan rejects common corruption markers before checkpointing.
- `ACCEPTANCE_MATRIX.md`, `ISSUE_QUEUE.md`, `PROJECT_STATE.md`, `QA_EVIDENCE.md`, and `ITERATION_LOG.md` record only demonstrated coverage; L10N-01 remains Partial until every pending row is complete.
