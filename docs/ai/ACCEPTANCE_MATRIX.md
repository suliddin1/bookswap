# Launch acceptance and authorization matrix

Updated: 1 August 2026

Status values: **PASS** = direct evidence exists; **BLOCKED** = a required safety/compatibility gate cannot be completed now; **DEFERRED/RISK-ACCEPTED** = the owner intentionally postponed it for friends-only beta but not public launch; **PRODUCTION** = can only be verified after deployment; **POST-LAUNCH** = outside MVP.

Current private-beta gate: the owner-designated clean beta project has exact 22-migration parity and passes remote SQL, Storage, advisor, and seven-role authorization checks with zero residue. The deployed Vercel Production release passes the prior public browser/runtime smoke, but P0-001's repository fix for iPhone listing authoring awaits an authorized deployment and post-deploy mobile verification. Friend self-signup and recovery also remain blocked by the external custom SMTP/Send Email Hook requirement; the legacy project stays paused and untouched.

## Authorization matrix

“Moderator” is intentionally not a privileged database role in the launch schema. A moderator-labeled ordinary account has normal-user permissions and cannot call admin/moderation actions. All current moderation state changes are admin-only and audited; a future moderator role requires an additive role/permission design.

## Strong pre-launch recommendations

- Docker-backed zero-to-head local reset and both SQL scripts.
- Repeat the approved networked dependency scan and adopt a compatible upstream fix for the known ESLint-only `brace-expansion` advisory when released; the current production-only audit is 0.
- Native Azerbaijani editorial and qualified legal review.
- Recovery/incident tabletop and isolated restore exercise.
- Additional manual authenticated browser exploration against development; the automated real backend actor matrix already passes.

## Post-launch acceptance

Automated exchange/wanted matching, sale/exchange/both intention, shelves, social reading, complete edition metadata, external search infrastructure, integrated payment/escrow/shipping, product analytics, paid listing promotion, professional seller plans, and direct sponsorships are not launch gates.
